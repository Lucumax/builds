# How I work

## Two errors my own checks passed

Before I published the GPU cost model, a separate AI reviewer found two errors that my checks had passed. I had credited a 35 percent discount to a pricing page that states no percentage. And a cover ratio compared a year five scrap value with the debt owed at the end of a one to three year contract. I relabeled the discount as an assumption and fixed the ratio. That is why I still read the output myself.

## The rule

An agent may read, draft, build to a spec, run checks and propose. Only a person may accept a decision, spend money, publish, change a gate or act on anything irreversible. I set that line before an agent starts.

## Autonomous agents

Agents in my own operation run on a schedule, read sources and draft. Anything that leaves my desk waits for my approval.
