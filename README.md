## How I work

I run AI builds the way a product owner runs an engineering team. I write the spec, the acceptance tests and the release gates. Claude Code conducts. Codex, open weight models such as DeepSeek and small checker models build, review and fact check. Other agents try to break what the first ones built, and nothing ships until I have read the output myself, because a passing test is not a good result. The question I put first in every build is what an agent may do alone and what only a person may approve.
